# 🛫 스마트 토잉카 관제 시스템 시나리오

본 문서는 **[관제탑 - 토잉카 - 기장 - 마샬러]** 4개 주요 객체 간의 상호작용 및 시스템 동작 절차를 정의한다.

## 1. 주요 객체 정의

| 객체 | 역할 및 주요 기능 |
| --- | --- |
| **관제탑** | 전체 시스템 통제, 경로 생성 및 할당, 비상 상황 시 구역 차단 및 재탐색 명령 |
| **토잉카** | 항공기 견인, 자율 주행, 객체(항공기, 마샬러) 인식, 수동/자동 모드 전환 |
| **기장** | 항공기 제어(브레이크), 관제탑과 통신(연결/이동 요청), 비상 정지 요청 |
| **마샬러** | (AI 인식 대상) 수신호를 통해 토잉카의 출발/정지 제어, 육안 안전 확인 |

## 2. 시나리오 1: 토잉카-항공기 연결 (도킹)
### 📝 진행 절차

1. **대기:** 토잉카는 지정된 게이트 위치에서 대기한다.
2. **연결 요청:** 승객 탑승 준비가 완료되면, 기장이 단말기를 통해 연결을 요청한다.
* *전송 데이터:* 비행기 식별 코드


3. **검증:** 시스템은 요청한 비행기 코드가 스케줄 상 매칭된 항공기와 일치하는지 확인한다.
4. **접근 및 정렬:**
* 검증 완료 시 토잉카는 비행기 객체를 인식하고 중앙으로 위치를 잡는다.
* **매칭 포인트(바퀴 중앙의 빨간 점)**를 인식하여 천천히 접근한다.


5. **결착:** 위치 확보 후 바퀴를 들어 올려 단단히 고정한다.
6. **완료 알림:** 결착이 완료되면 관제탑과 기장에게 완료 메시지를 전송한다.

---

## 3. 시나리오 2: 이동 승인 및 주행

**[목표]** 게이트에서 활주로 또는 격납고로 안전하게 이동한다.

### 📝 진행 절차

1. **이동 요청:** 기장이 도킹 완료 메시지를 확인한 후, 목적지(활주로/격납고) 이동을 요청한다.
2. **경로 할당 및 명령:** 관제탑은 목적지에 따른 최적 경로를 생성하여 토잉카와 기장에게 전송한다.
* *예시 A:* 1번 활주로 이동 시 → A 경로 할당
* *예시 B:* K 격납고 이동 시 → Y, Z 경로 할당


3. **최종 점검:** 기장은 브레이크 해제 등 기체 점검을 마치고(마샬러와 소통), 토잉카에게 '이동 승인' 신호를 보낸다.
4. **출발 판단 로직:** 토잉카는 주변 마샬러 유무에 따라 다르게 동작한다.
* **마샬러가 있는 경우:** 마샬러의 **[출발 수신호]**를 AI가 인식했을 때 출발한다.
* **마샬러가 없는 경우:** 기장의 이동 승인 신호를 받으면 즉시 출발한다.


5. **주행 중 제어:** 주행 중 마샬러의 **[정지 수신호]**가 탐지되면 즉시 정지한다.

---

## 4. 시나리오 3: 비상 상황 및 수동 제어

**[상황]** 주행 중 긴급 상황 발생 시 대처 프로세스이다.

### 📝 진행 절차

1. **긴급 정지:** 아래 상황 발생 시 토잉카는 급정거한다.
* 마샬러의 정지 신호 감지
* 기장의 긴급 정지 요청
* 토잉카 자체 센서의 장애물 감지


2. **수동 모드 전환:** 시스템은 즉시 **수동 모드**로 전환되며, 제어 권한이 **비상 운전수**에게 부여된다.
3. **상황 해결 및 재출발:**
* **마샬러 통제 시:** 마샬러의 **[출발 수신호]**가 다시 감지되면 출발한다.
* **관제 통제 시:** 비상 운전수가 상황을 해결하고 수동 모드를 해제한다. 이후 관제탑의 재출발 승인을 받아 이동을 재개한다.



---

## 5. 시나리오 4: 경로 재탐색

**[상황]** 활주로 파손이나 장애물 등으로 인해 기존 경로를 이용할 수 없는 경우이다.

### 📝 진행 절차

1. **이상 감지 및 정지:** 마샬러(수신호) 또는 기장(판단)에 의해 이상이 감지되어 정지한다.
2. **상황 보고:** 마샬러 또는 기장이 관제 센터에 문제를 보고한다.
3. **구역 차단:** 관제탑은 해당 활주로(구역)를 **[이용 불가]**로 설정하고 경로 노드를 차단한다.
4. **경로 재탐색:**
* **기준점:** 현재 비행기가 **마지막으로 지나친 노드**를 기준으로 한다.
* **탐색:** 차단된 구간을 우회하여 목적지까지 가는 새로운 경로를 계산한다.


5. **경로 전달 및 이동:**
* 관제탑은 토잉카에게 수정된 경로를 전송한다.
* 토잉카는 **이전 노드로 이동(후진 등)**한 뒤, 새로 전달받은 경로를 따라 주행한다.



---

## 6. 시나리오 5: 도착 및 복귀

### 📝 진행 절차

1. 목표 지점(활주로 끝단 또는 격납고)에 도착한다.
2. 항공기 바퀴 결착을 해제하고 물러난다.
3. 토잉카는 관제탑의 다음 명령(대기 장소 또는 충전소 이동)에 따라 **자동으로 복귀**한다.
