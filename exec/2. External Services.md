# 2. 외부 서비스 정보

## 1. 개요

본 프로젝트에서 활용하는 외부 서비스 및 연동 정보를 기술합니다.

## 2. 외부 서비스 목록

### 2-1. Messaging & Broker

- **서비스명**: MQTT Broker (EMQX 등)
- **용도**:
  - AI 모듈(Towing Car)과 Backend/Frontend 간의 실시간 제어 메시지 전송
  - 상태 모니터링 데이터 스트리밍
- **접속 정보**:
  - **Host**: `autowingcar.o-r.kr` (Environment Variable `MQTT_HOST` 참조)
  - **Port**: `8883` (SSL/TLS, `MQTT_PORT` 참조)
  - **Protocol**: MQTT over SSL/TLS (WSS for Frontend)
  - **Dependencies**:
    - Backend: `org.eclipse.paho:org.eclipse.paho.client.mqttv3`
    - Frontend: `mqtt` (npm package)

### 2-2. Data Storage & Cache

- **서비스명**: Redis (Optional / Prod)
- **용도**: 세션 저장소, 메시지 브로커 보조, 캐싱
- **접속 정보**:
  - **Host/Port**: `localhost:6379` (Default, `REDIS_HOST` 참조)
  - **Dependencies**: `spring-boot-starter-data-redis`

### 2-3. Notification

- **서비스명**: Mattermost (Webhook)
- **용도**: GitLab CI/CD 파이프라인 상태 및 Merge Request 알림
- **설정**: `MATTERMOST_WEBHOOK_URL` 환경 변수 사용

## 3. API 및 SDK

- **Social Auth**: 코드베이스 분석 결과, 별도의 외부 소셜 로그인(Kakao, Google 등) SDK는 발견되지 않았습니다. (자체 JWT 인증 사용)
- **Maps**: 외부 지도 API(Google Maps, Naver Maps) 대신 자체적으로 정의된 로컬 맵 데이터(`node_*.json`, `edge_*.json`)를 사용하는 것으로 파악됩니다.

## 4. 기타

- **AI/Vision**: OpenCV와 PyTorch(YOLOv8) 모델을 로컬에서 구동하며, 별도의 클라우드 비전 API는 사용하지 않습니다.
