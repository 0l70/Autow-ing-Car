# 4. 시연 시나리오

## 1. 사전 준비 (Prerequisites)

1. **서버 구동**: Backend (Local/Prod), Frontend, MQTT Broker 실행 상태 확인.
2. **AI 모듈 실행**: Towing Car 내 Jetson/PC에서 `main.py` 실행 및 카메라(Webcam) 정상 작동 확인.
3. **네트워크**: 모든 기기(서버, 클라이언트, Towing Car)가 동일 네트워크 또는 MQTT 브로커에 접속 가능한 상태.

## 2. 시연 순서 및 상세 설명

### [Step 1] 웹 관제 시스템 접속 및 모니터링

- **화면**: 메인 대시보드 (Dashboard)
- **행동**:
  1. 웹 브라우저로 관제 시스템 접속.
  2. 로그인 (필요 시).
  3. **"Connect Tug"** 버튼 클릭 또는 자동 연결 상태 확인.
  4. 대시보드 상에서 Towing Car의 현재 상태(Battery, Connection Status 등)가 실시간으로 갱신되는지 확인.

### [Step 2] 미션 생성 및 할당 (Mission Assignment)

- **화면**: 맵 뷰 (Map View)
- **행동**:
  1. 출발지(Start Node)와 목적지(End Node)를 지도 상에서 클릭.
  2. 경로 생성 확인 후 **"Start Mission"** 버튼 클릭.
  3. 하단 로그/상태창에 "Mission Started" 메시지 출력 확인.

### [Step 3] 자율 주행 및 마샬링 (Autonomous Driving / Marshal)

- **화면**:
  - (Web) 실시간 차량 위치 이동 (Map Tracking)
  - (AI View) `main.py` 실행 창 (카메라 뷰)
- **행동**:
  1. 차량이 목적지 인근 또는 특정 구역(Marshal Zone)에 진입.
  2. AI 모듈 상태가 `MARSHAL` 모드로 전환됨을 확인 (화면 상단 "MODE: MARSHAL" 표시).
  3. **제스처 인식 시연**:
     - 카메라 앞에서 손짓(Gesture)을 수행 (예: Stop, Move Forward 등).
     - 차량이 제스처에 반응하여 정지하거나 이동하는지 확인.
     - 웹 대시보드에 상태 변화 반영 확인.

### [Step 4] 도킹 (Docking)

- **화면**: AI View (Camera View)
- **행동**:
  1. 차량이 도킹 스테이션(ArUco Marker) 근처로 이동.
  2. AI 모듈 상태가 `DOCKING` 모드로 전환 (또는 수동 키 'd' 입력).
  3. **ArUco 마커 인식**:
     - 화면에 마커 ID 및 거리(Dist), 각도(Yaw) 정보 표시.
     - 녹색/노란색 가이드라인에 맞춰 차량이 미세 조정하며 접근.
  4. 도킹 완료 메시지("DOCKING COMPLETE!") 출력 및 정지.

### [Step 5] 시연 종료 및 복귀

- **화면**: 메인 대시보드
- **행동**:
  1. 미션 완료(Mission Completed) 알림 확인.
  2. 필요 시 **"Return to Base"** 명령 수행.
