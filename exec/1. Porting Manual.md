# 1. Porting Manual

## 1. 개요

본 문서는 GitLab 소스 클론 이후 프로젝트를 빌드 및 배포하기 위한 환경 설정 및 절차를 기술합니다.

## 1-1. 개발 환경 및 기술 스택 (Tech Stack)

### Backend

- **Language**: Java 17
- **Framework**: Spring Boot 3.5.9
- **Build Tool**: Gradle (Wrapper 포함)
- **Database**:
  - Runtime (Dev): H2 Database (In-memory)
  - Production: PostgreSQL (설정 파일 기준)
  - Cache/Message Broker: Redis
- **Security**: Spring Security, JWT
- **Communication**: WebSocket (STOMP), MQTT (Eclipse Paho)

### Frontend

- **Language**: TypeScript (`^5.6.2`)
- **Framework**: React (`^18.3.1`)
- **Build Tool**: Vite (`^6.0.3`)
- **Package Manager**: pnpm (`10.28.1`)
- **Styling**: TailwindCSS (`^3.4.17`)
- **Runtime**: Node.js 22.12.0

### AI / Embedded

- **Language**: Python 3.x
- **Libraries**: OpenCV (`cv2`), NumPy, PyTorch (YOLOv8)

### Infrastructure & Tools

- **Web Server**: Nginx (Frontend Serving)
- **IDE**: IntelliJ IDEA (Backend), VS Code (Frontend/AI)
- **Containerization**: Docker (Dockerfile included for Backend & Frontend)

## 1-2. 빌드 및 실행 환경 변수 (Environment Variables)

CI/CD 파이프라인(GitLab CI) 및 운영 환경에서 사용되는 전체 환경 변수 목록입니다.

### 1. CI/CD & Deployment (GitLab CI / EC2)

| 변수명                    | 설명                        | 비고                          |
| ------------------------- | --------------------------- | ----------------------------- |
| `BACKEND_DOCKER_USERNAME` | Docker Hub 계정 ID          | 이미지 Push/Pull 용도         |
| `BACKEND_DOCKER_PASSWORD` | Docker Hub Access Token     | 이미지 Push/Pull 용도         |
| `EC2_IP`                  | 배포 서버(AWS EC2) IP 주소  | SSH 접속 대상                 |
| `SSH_PRIVATE_KEY`         | EC2 접속용 SSH Private Key  | PEM 키 내용 (Line break 포함) |
| `MATTERMOST_WEBHOOK_URL`  | Mattermost 알림 Webhook URL | MR 이벤트 알림 전송           |

### 2. Backend Runtime (`application.yml` / `deploy.env`)

| 변수명           | 설명                       | 예시 값                                |
| ---------------- | -------------------------- | -------------------------------------- |
| `MQTT_HOST`      | MQTT 브로커 호스트 주소    | `autowingcar.o-r.kr`                   |
| `MQTT_PORT`      | MQTT 브로커 포트           | `8883`                                 |
| `REDIS_HOST`     | Redis 호스트               | `localhost` (Docker: `autowing-redis`) |
| `REDIS_PORT`     | Redis 포트                 | `6379`                                 |
| `JWT_SECRET`     | JWT 서명 시크릿 키         | (Base64 Encoded String)                |
| `JWT_EXPIRATION` | JWT 만료 시간 (ms)         | `86400000`                             |
| `DB_URL`         | (Prod) PostgreSQL JDBC URL | `jdbc:postgresql://HOST:PORT/DB`       |
| `DB_USERNAME`    | (Prod) DB 사용자명         | `postgres`                             |
| `DB_PASSWORD`    | (Prod) DB 비밀번호         | `password`                             |

### 3. Frontend Build (`.env` / Docker Build Args)

| 변수명              | 설명                 | 예시 값                           |
| ------------------- | -------------------- | --------------------------------- |
| `VITE_API_BASE_URL` | 백엔드 API 기본 주소 | `https://api.autowingcar.o-r.kr`  |
| `VITE_WS_BASE_URL`  | 웹소켓 서버 주소     | `wss://api.autowingcar.o-r.kr/ws` |

## 1-3. 배포 시 특이사항

1. **Docker 빌드**:
   - Backend와 Frontend 각각 `Dockerfile`이 존재하므로 Docker 이미지를 빌드하여 배포하는 것을 권장합니다.
   - Frontend는 Nginx를 통해 정적 파일을 서빙하도록 구성되어 있을 수 있습니다 (`Frontend/nginx` 폴더 참조).

2. **Database**:
   - 개발(`dev`) 프로파일에서는 H2 데이터베이스를 사용하므로 데이터가 휘발됩니다.
   - 운영(`prod` / `master`) 프로파일 배포 시 반드시 PostgreSQL이 설치되어 있어야 하며, `application-prod.yml`에 정의된 `DB_URL` 정보를 환경 변수로 주입해야 합니다.

3. **HTTPS/SSL**:
   - MQTT 연결이 `ssl://` 스키마를 사용하므로, 브로커가 SSL을 지원해야 하며 인증서 설정이 필요할 수 있습니다.

4. **AI 모듈**:
   - Python 환경에서 `requirements.txt` (또는 이에 준하는 의존성) 설치 후 `main.py`를 실행해야 합니다.
   - 카메라(Webcam) 접근 권한이 필요합니다.

## 1-4. 주요 계정 및 프로퍼티 정의 파일 (Protected Files)

다음 파일들은 DB 접속 정보, API Key, Secret 등을 포함할 수 있으므로 보안에 유의해야 합니다.

1. **`/.env`**: 프로젝트 루트의 환경 변수 파일 (MQTT, Redis, JWT Secret 포함).
2. **`Backend/autowing_car/src/main/resources/application.yml`**: Spring Boot 기본 설정.
3. **`Backend/autowing_car/src/main/resources/application-prod.yml`**: 운영 환경 DB 설정 (Env Var 참조하지만 구조 노출).
4. **`Frontend/package.json`**: 프론트엔드 의존성 및 스크립트 정보.
