# 프로젝트 구조 및 기술 설명서 (Non-Developers Guide)

이 문서는 React 도메인 지식이 없는 분이 이 프로젝트의 구조와 작동 원리를 타인에게 설명할 수 있도록 돕기 위해 작성되었습니다.

---

## 1. 기술 스택 (도구 설명)

우리가 건물을 짓는다고 상상해봅시다. 이 프로젝트에서 사용된 도구들은 다음과 같은 역할을 합니다.

- **Vite (비트)**: **'최신식 건설 장비'**입니다. 옛날 방식보다 훨씬 빠르게 건물의 뼈대를 세우고, 수정 사항을 즉시 볼 수 있게 해줍니다. (개발 서버 구동 속도가 매우 빠름)
- **React (리액트)**: **'레고 블록 시스템'**입니다. 화면을 큰 덩어리로 한 번에 만드는 게 아니라, '버튼', '카드', '패널' 같은 작은 부품(컴포넌트)을 조립해서 만듭니다.
- **TypeScript (타입스크립트)**: **'설계 도면 검사기'**입니다. "이 나사는 5mm 구멍에만 들어간다"처럼 규칙을 미리 정해서, 건설 중에 엉뚱한 부품을 끼우는 실수를 미리 막아줍니다.
- **Tailwind CSS (테일윈드)**: **'미리 준비된 인테리어 키트'**입니다. CSS 코드를 따로 길게 짜는 대신, `bg-red-500` (빨간 배경), `text-xl` (큰 글씨) 같은 이름표를 붙여서 즉시 꾸밉니다.

## 2. 화면 구조 (레이아웃) 설명

이 관제 시스템(**Masterboard UI**)은 크게 **3개의 구역(3-Zone Layout)**으로 나뉩니다. 파일로는 `src/shared/ui/layout/MainLayout.tsx`에 정의되어 있습니다.

### [구역 1] 왼쪽 패널 (Left Panel) - "상황판"

- **위치**: 화면 왼쪽의 좁은 구역 (Sidebar).
- **역할**: 전체적인 알림과 로그를 보여줍니다.
- **구성 요소**:
  1.  **Critical Alerts (`ApprovalQueue.tsx`)**:
      - "빨간색 네온"으로 긴급한 알림을 표시합니다.
      - 예: 충돌 경고(COLLISION WARNING), 승인 대기(APPROVAL NEEDED).
  2.  **Activity Timeline (`ActivityTimeline.tsx`)**:
      - "청록색(Cyan) 네온"으로 시스템의 모든 활동 기록을 시간순으로 보여줍니다.
      - 예: 로그인, 데이터 수신, 경로 변경 로그.

### [구역 2] 중앙 패널 (Center Map) - "메인 전장"

- **위치**: 화면 중앙의 가장 넓은 공간.
- **역할**: 실제 항공기와 토잉카의 위치, 이동 경로를 시각적으로 보여줍니다.
- **구성 요소 (`DashboardPage.tsx`)**:
  - **SVG 맵**: 지도를 그림(Vector) 방식으로 그립니다. 확대/축소해도 깨지지 않습니다.
  - **경로(Route)**: 항공기가 이동할 길을 주황색 선으로 표시.
  - **항공기(Aircraft)**: 현재 추적 중인 비행기 아이콘과 레이더 효과(물결 표시).

### [구역 3] 오른쪽 패널 (Right Panel) - "상세 분석실"

- **위치**: 화면 오른쪽 패널 (Inspector).
- **역할**: 선택한 대상의 구체적인 정보를 깊게 파고듭니다.
- **구성 요소 (`MissionInspector.tsx`)**:
  1.  **Selected Mission**: 현재 수행 중인 미션 정보 (항공기 번호, 게이트 정보, 진행률 바).
  2.  **Connection (Live Feed)**:
      - **카메라(WebRTC)**: 실제 현장 영상을 띄우는 화면 (현재는 NO SIGNAL 예시 화면).
      - **텔레메트리(Telemetry)**: 속도(SPEED), 방향(HEADING), 좌표(POS X, Y)를 실시간 계기판처럼 보여줍니다.

## 3. 디자인 컨셉 (스타일링)

이 프로젝트는 **"Dark Ops + Neon Laser" (어두운 작전실 + 네온 레이저)** 컨셉으로 만들어졌습니다.

- **Glassmorphism (유리 효과)**: 패널 배경을 반투명 검은색으로 만들고 뒤를 흐리게(`backdrop-blur`) 처리하여, 마치 미래의 유리 화면 위에 떠 있는 느낌을 줍니다.
- **Neon Glow (네온 발광)**: 중요한 정보는 단순히 색만 칠하는 게 아니라, 주변에 빛이 번지는 효과(`drop-shadow`)를 줘서 눈에 확 띄게 했습니다.
  - 🔴 **Red**: 위험, 경고 (Alerts)
  - 🟠 **Orange**: 메인 경로, 현재 선택된 미션 (Main Mission)
  - 🟢 **Lime**: 연결 상태, 양호 (Connection)
  - 🔵 **Cyan**: 정보, 시스템 로그 (Info)
- **폰트 (Typography)**:
  - **Inter (Apple System)**: 제목 등 큰 글씨는 깔끔하고 가독성 좋게 (현대적인 느낌).
  - **SF Mono / JetBrains Mono**: 숫자, 좌표, 로그는 코딩 화면처럼 딱딱 떨어지는 고정폭 글꼴 사용 (전문적이고 기계적인 느낌).

## 4. 데이터 흐름 (설명 포인트)

"이 화면의 숫자는 어떻게 바뀌나요?"라고 물어본다면:

1.  **현재 상태**: 지금은 **'Mock Data(모조 데이터)'**입니다. 즉, 화면이 어떻게 보일지 디자인하기 위해 우리가 임의로 넣어둔 가짜 숫자들입니다.
2.  **미래 계획**: 백엔드(서버)와 연결되면, 실제 항공기가 움직일 때마다 서버가 새로운 좌표와 속도를 보내줍니다. 리액트는 그 숫자를 받아서 **"깜빡거림 없이"** 부드럽게 화면의 숫자만 샥 바꿈니다. (이게 리액트를 쓰는 이유입니다!)
